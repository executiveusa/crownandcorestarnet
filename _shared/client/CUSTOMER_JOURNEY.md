# Customer journey

## Working journey

```
DISCOVERY
-> WEBSITE / PROFILE / CONTENT
-> INQUIRY OR DIRECT BOOKING
-> RESPONSE
-> BOOKING
-> REMINDER
-> SHOW
-> VISIT / PURCHASE
-> FOLLOW-UP
-> RETURN
-> FEEDBACK
-> OPTIONAL REVIEW
-> REFERRAL
```

## Audit rule

At each step capture:
- volume entering,
- volume leaving,
- time delay,
- owner/staff responsibility,
- system used,
- measurable loss,
- evidence source.

Do not label a step broken until evidence exists.

## Priority

Prefer the verified leak closest to completed payment/visit, unless risk, compliance, capacity, or owner direction makes another step more important.
