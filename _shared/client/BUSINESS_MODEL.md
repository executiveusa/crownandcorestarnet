# Business model working map

This document separates known structure from numbers that still need owner verification.

## Revenue areas previously identified

- Wellness
- Spa
- Hair
- Performance Therapy
- Packages / memberships
- Retail / hair products where applicable
- Events where applicable

## Variables required for prioritization

For each service:
- price
- gross margin estimate
- provider/room capacity
- average booking duration
- repeat interval
- new vs returning mix
- cancellation/no-show rate
- demand level
- visual/media potential
- compliance complexity

## Hero-service scoring

A candidate service can be scored on:

```
Margin
x Available Capacity
x Repeatability
x Visual Story
x Customer Demand
x Compliance Simplicity
```

The score is a decision aid, not a substitute for owner judgment.
