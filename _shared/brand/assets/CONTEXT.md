# Brand Assets Contract

One job: protect and route Crown & Core's approved public assets.

## Rules
- Original logo files are canonical.
- Never regenerate a logo because a file is missing.
- Never trace, redraw, recolor, distort, or replace a logo without approval.
- Generated web derivatives must point back to the original asset.
- Preserve provenance: source, date received, and approval state.
- Do not invent photography or treatment imagery and present it as Crown & Core.

## Required asset classes
- `logos/`
- photography
- video
- icons/social marks when approved

## Current status
Canonical logo binaries are not yet present in this repository. This is a blocker for final branded production output, not permission to fabricate them.
