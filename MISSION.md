# Crown & Core — Mission Lock

## Primary mission

Build and prove a substantially better Crown & Core digital experience than the current public website, using Crown & Core's real business truth, real brand assets, real services, real booking path, and verified customer needs.

The website is the product.

ICM is the operating architecture.
Instinct/StarNet is the future conversational operator.
GitHub is the auditable source of truth.
Runtime and deployment are supporting infrastructure.

## Success condition

The work is successful only when:

1. the Crown & Core website exists as a working artifact;
2. it is unmistakably Crown & Core rather than a copy of a reference site;
3. mobile, accessibility, booking path, performance, SEO, and core routes are verified;
4. claims and public facts are evidence-backed;
5. a fresh critic can compare it against the current site and chosen category references;
6. ordinary future site changes can be routed safely through ICM and executed conversationally with human approval where required.

## Reference law

RUMA and other high-quality sites are adversarial quality bars, not visual templates.

Extract principles. Do not copy finished compositions, identity, motion systems, or page structure.

## Anti-drift rules

Do not turn this mission into:
- a generic marketing consultancy project;
- an agent-framework project;
- a runtime engineering project;
- a RUMA clone;
- an animation showcase;
- an architecture exercise without a site;
- an offer strategy project detached from the website;
- a replacement of working booking infrastructure without verified cause.

When a supporting system competes with producing or improving the website, the website wins.

## Current execution priority

1. establish verified baseline;
2. recover and protect real Crown & Core brand assets;
3. define the site's governing idea and decision journey;
4. build the smallest complete homepage + booking path slice;
5. verify it;
6. expand only after the slice survives the Gauntlet.

## Human authority

Brand-defining changes, public clinical claims, booking/payment changes, legal copy, domain/DNS, destructive actions, and production release require the declared human gate.

Agent prose is never proof of completion.
