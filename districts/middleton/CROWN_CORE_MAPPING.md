# Middleton method -> Crown & Core

| Middleton layer | Crown & Core implementation |
|---|---|
| Conversion website | Mobile service paths, Perspective funnels, Square booking handoff |
| Reactivation | R3 dormant-customer return campaigns |
| Reviews + referrals | Private feedback, optional honest review, referral path |
| Lead nurturing | Fast inquiry follow-up, reminders, no-show recovery |
| Receptionist | Missed-call / after-hours capture with human escalation |
| Sales coach | Front-desk and consultation QA/training |
| Paid marketing | Meta/other paid distribution only after gates pass |

## Media layer added for Crown & Core

Crown & Core also has a dedicated Media room:
- Crown & Core Podcast
- Riverside recordings
- founder interviews
- expert/vendor interviews
- reusable B-roll
- short-form clips
- service education
- landing-page message match

This is not a replacement for the Middleton sequence. It is the trust/content engine feeding it.
