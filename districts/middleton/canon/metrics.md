# Middleton metrics

The source pack contains benchmark numbers used in JP Middleton's pitches.

## Rule

**Do not publish these as Crown & Core facts.**

Treat them as:
- research prompts,
- hypotheses,
- comparison points to verify,
- questions to test against Crown & Core's own data.

## Metrics to measure directly for Crown & Core

- mobile load time
- booking completion rate
- inquiry response time
- missed calls
- no-shows
- completed visits
- repeat visits
- dormant customers 90+ days
- review request rate
- review completion rate
- referral volume
- ad spend
- attributable bookings
- attributable revenue
- customer acquisition source
- service-level capacity
- service-level margin where available

The source claims and video references remain in `system.json`.
