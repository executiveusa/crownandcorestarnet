# Crown & Core execution policy for Middleton District

The canon records what JP Middleton teaches. This file controls what Crown & Core may actually execute.\n\n**Crown & Core policy wins over canon.**

## Precedence

1. Owner approval
2. Crown & Core safety/compliance rules
3. Crown & Core business facts
4. Verified live data
5. Middleton canon
6. Experiment ideas

## Review rule

Do **not** implement review gating.

Allowed flow:

```
PRIVATE FEEDBACK
-> same treatment regardless of sentiment
-> optional honest public review
-> reward independent of positive rating or public review
```

A negative or neutral response must not reduce access to the public-review option.

## Claims rule

Do not publish Middleton's benchmark numbers as Crown & Core facts unless independently verified and properly sourced.

Do not convert source claims about wellness outcomes into Crown & Core medical claims.

## Reactivation rule

Reactivation requires:
- owner-approved audience,
- valid consent/marketing basis,
- owner-approved offer,
- owner-approved message,
- opt-out handling,
- event logging,
- booking/revenue measurement.

## Paid media rule

Paid media is last. It requires:
- mobile destination verified,
- booking path verified,
- response/follow-up verified,
- attribution ready,
- owner approval,
- explicit budget,
- stop condition.

## Experiment rule

Every experiment must contain:
- hypothesis,
- evidence,
- smallest test,
- audience,
- cost ceiling,
- metric,
- stop condition,
- rollback,
- approval receipt.
