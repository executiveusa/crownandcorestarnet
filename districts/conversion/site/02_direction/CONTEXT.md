# 02_direction — decide what the site should be

One job: convert verified business/customer truth into an original Crown & Core website direction.

## Inputs
- `../01_baseline/output/baseline.md`
- `../01_baseline/output/content-inventory.md`
- `../01_baseline/output/asset-inventory.md`
- `../../../../../_shared/brand/CONTEXT.md`
- approved reference principles only

## Process
1. Define the visitor's primary job and decision sequence.
2. Define Crown & Core's governing idea.
3. Define visual world, typography behavior, image language, density, composition, motion language, and anti-references.
4. Define homepage information architecture and booking path.
5. Specify one signature interaction only if it performs a real job.

## Outputs
- `output/direction.md`
- `output/homepage-brief.md`
- `output/reference-ledger.md`

## Human check
Approve the governing visual direction before a brand-defining build.

## Do NOT load
Unrelated district strategy or imitate a reference site's finished design.
