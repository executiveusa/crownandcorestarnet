# Website Product

This directory is reserved for the actual Crown & Core website product.

It is intentionally not pre-filled with speculative framework code.

The first implementation must be chosen from verified baseline constraints in `../01_baseline/output/baseline.md` and the approved direction in `../02_direction/output/direction.md`.

A strategy document is not the product.
A screenshot is not the product.
A deployed but unverified build is not the product.
