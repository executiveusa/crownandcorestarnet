# Crown & Core Website Challenge

## One job
Build and prove the Crown & Core website experience. This is the primary product mission for the conversion district.

## Mission input
- `../../../MISSION.md`

## Stable inputs
Load only what the current stage declares from:
- `../../../_shared/client/`
- `../../../_shared/brand/`
- `../../../_shared/evidence/`

## Sequence
1. `01_baseline/` — establish verified current-state evidence.
2. `02_direction/` — define governing idea, hierarchy, and customer decision journey.
3. `03_build/` — build the smallest complete website slice.
4. `04_verify/` — independent functional and quality proof.
5. `05_release/` — publish only after the declared gate.

## Product
Working website artifacts belong under `product/`.
Stage outputs are decision/proof surfaces, not substitutes for the product.

## Human check
Major visual direction, clinical/public claims, booking/payment changes, and production release require explicit approval.

## Done
Not "coded." Not "previewed." Done means built, rendered, interactive, verified, approved where required, and release evidence recorded.

## Do NOT load
Unrelated StarNet districts, runtime internals, reactivation strategy, reception workflows, or performance experiments unless a stage explicitly requires them.
