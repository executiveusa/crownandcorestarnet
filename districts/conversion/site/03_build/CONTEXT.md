# 03_build — produce the website

One job: turn the approved direction into a working site.

## Inputs
- `../02_direction/output/direction.md`
- `../02_direction/output/homepage-brief.md`
- verified Crown & Core content and canonical assets declared by the brief

## Process
1. Build the smallest complete responsive slice first.
2. Keep content readable before animation.
3. Preserve native scrolling and controls.
4. Reuse the verified booking destination unless a change is explicitly approved.
5. Use canonical assets; generated derivatives are build outputs.
6. Keep implementation reversible.

## Outputs
- working files under `../product/`
- `output/build-note.md` recording changed routes/files and unresolved items

## Human check
Preview required before major visual changes proceed to release.

## Do NOT load
Unrelated business-operation districts or fabricate missing proof/assets.
