Production path

Approval-gated
  1. Build source-verified brief
  2. Owner reviews story, positioning and creator rights
  3. Clinical/legal review for regulated claims
  4. Verify actual Motion Master or Montage renderer adapter
  5. Authorize capped rendering job
  6. Inspect playable video, provenance and quality
  7. Approve exact publication revision
  8. Measure qualified inquiries and bookings when attribution is connected

This prototype deliberately has no rendering provider API calls, analytics claims, customer records, ad spend, or publication action.
